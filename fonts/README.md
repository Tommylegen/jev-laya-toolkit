# Font

Ketiga keluarga font di folder ini berlisensi **SIL Open Font License 1.1**
(teks lisensi: `LICENSE-inter.txt`, `LICENSE-fraunces.txt`,
`LICENSE-jetbrains-mono.txt`), disalin dari paket
[Fontsource](https://fontsource.org/) supaya dashboard bisa jalan tanpa CDN.

| Berkas | Keluarga | Peran di UI |
|---|---|---|
| `fraunces-latin-600/700-normal.woff2` | Fraunces | judul & display |
| `inter-latin-400/500/600-normal.woff2` | Inter | teks antarmuka |
| `jetbrains-mono-latin-400/500-normal.woff2` | JetBrains Mono | data & angka |
